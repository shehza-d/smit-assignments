# Mobile App Development

## React Native or Expo

### 1. Notes App (Best simple upgrade)

- Create / edit / delete notes
- Store locally or in Supabase
- Add timestamps

Why good: teaches CRUD + real use case

---

### 2. Expense Tracker (Very useful)

- Add income/expense
- Show total balance
- Simple list + calculations

Why good: teaches state + basic logic

---

### 3. Weather App

- Search city
- Show temperature + condition
- Uses API (OpenWeather etc.)

Why good: teaches API fetching

---

### 4. Habit Tracker

- Mark habits daily
- Streak counter
- Simple progress UI

Why good: teaches arrays + state updates

---

### 5. Contact List App

- Add contacts (name, number)
- Search contacts
- Delete/edit

Why good: real-world CRUD + filtering

---

### 6. Quote Generator App

- Fetch random quotes API
- Button to refresh quote
- Save favorites

Why good: very easy + API practice

---

### Best recommendation for your 2–4 classes:

👉 **Expense Tracker or Notes App**

They cover:

- components
- props/state
- lists
- CRUD
- simple UI logic

If you want, I can also give you a **step-by-step class plan (what to teach in each session)** for one of these apps.
