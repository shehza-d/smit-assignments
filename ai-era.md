You probably can’t fully stop AI usage anymore, but you _can_ design assignments so copying becomes less useful and understanding becomes necessary.

Best approach is not “fight GPT”, but make assignments require:

- modification,
- explanation,
- personalization,
- live coding,
- debugging.

---

# ✅ What actually works

## 1. Give Requirements, NOT Step-by-Step Instructions

❌ Bad:

```md
1. Create variable called age
2. Use prompt
3. Show output
```

Students paste directly into GPT.

---

✅ Better:

```md
Build a small app that asks the user for information and displays a meaningful result.

Requirements:

- Use at least 3 variables
- Use prompt()
- Use mathematical calculation
- Output must be formatted clearly
```

Now they must think a little.

---

# ✅ 2. Add “Custom Rules”

Make each student slightly personalize it.

Example:

```md
Use your own:

- city
- favorite fruit
- dream salary
```

Or:

```md
Change colors/theme yourself
```

Copied solutions become obvious.

---

# ✅ 3. Ask Them to Explain Code

This is VERY powerful.

After assignment:

```md
Explain:

- why you used let/const
- why Number() was needed
- what would happen without conversion
```

A copied solution breaks here.

---

# ✅ 4. Give Tiny Live Changes in Class

After submission:

```txt
Now add:
- reset button
- dark mode
- remove last task
```

Students who copied usually collapse instantly.

---

# ✅ 5. Use “Incomplete Requirements”

Real developers work with ambiguity.

Instead of:

```md
Make exactly this UI
```

Try:

```md
Design must:

- contain 3 sections
- be responsive
- have hover effects
```

Now creativity matters.

---

# ✅ 6. Give Debugging Tasks (VERY underrated)

GPT is good at generating code.
Students are weak at fixing code.

Example:

```js
let total = num1 + num2;
```

Where `num1` and `num2` are prompts.

Ask:

```md
Why is output wrong?
Fix it.
```

This builds real skill.

---

# ✅ 7. Make Assignments Progressive

Instead of isolated tasks:

Week 1:

- Todo UI

Week 2:

- Add tasks

Week 3:

- localStorage

Week 4:

- filters

A student who copied week 1 struggles later.

---

# ✅ 8. Evaluate During Lab/Class

Even 5 minutes helps.

Ask:

- “What does this line do?”
- “Why array here?”
- “Can you change this?”

You instantly know who understands.

---

# ✅ 9. Add One “Thinking” Requirement

Example:

```md
Add one feature of your own.
```

This single line changes everything.

---

# ❌ What NOT to do

- Extremely long instructions
- Fully detailed algorithms
- Exact code structure
- “Type this then this then this”

That becomes a GPT prompt.

---

# 🔥 Best Combination

For each assignment:

```md
📌 Objective
📌 Requirements
📌 Constraints
📌 Bonus Challenge
📌 Explain Your Logic
```

NOT:

```md
📌 Step 1
📌 Step 2
📌 Step 3
```

---

# 💡 Biggest truth

Students who want to cheat will use GPT anyway.

Your goal is:

- make cheating less effective,
- reward understanding,
- create projects that evolve over time.

That’s enough.
