# Login Validation

## 🎯 Objective

Username aur password check karein.

## 📥 Input / Output

```bash
Username: admin
Password: 1234
Output: Login Successful
```

```bash
Username: shehzad
Password: 1111
Output: Incorrect Username or Password
```

## 📌 Requirements

- Logical operators use karein
- if/else use karein

## ⭐ Bonus

Galat password par "Try password again" show karein.
