# Convert temperature

## 🎯 Objective

Phale Celsius ko Fahrenheit me convert karein.

- Celsius → Fahrenheit **Formula**: $F = C \times \frac{9}{5} + 32$

- 25°C → 77°F

Phir ye Fahrenheit ko Celsius ma convert karein and dono ko mix/confuse nhi karna

- Fahrenheit → Celsius **Formula**: $C = (F - 32) \times \frac{5}{9}$

- 98°F → 36.6°C

## ⭐ Bonus

Rounded value show karein.
