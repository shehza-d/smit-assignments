# Title Case Converter (Hard)

## 🎯 Objective

Sentence ke har word ka first letter capital karein.

## 📥 Input

```py
"hello world from javascript"
"mY NaMe IS shehzad"
```

## 📤 Expected Output

```py
"Hello World From Javascript"
"My Name Is Shehzad"
```
